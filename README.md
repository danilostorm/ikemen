# Ikemen GO – Street Fighter Alpha/Zero

Projeto customizado para Windows com foco em **CPU vs CPU / Watch Infinito para live**.

## Estado atual

- Street Fighter Alpha/Zero base
- personagens e fases adicionais integrados
- Watch Infinito CPU vs CPU
- AI nível 8 aplicada após a seleção dos lutadores
- rotação por shuffle bag para reduzir repetições do elenco
- troca automática de personagens e fase após cada luta
- saída pelo `Esc`

## Organização

Os arquivos do projeto permanecem versionados neste repositório. Pacotes grandes de distribuição devem ficar em GitHub Releases, evitando armazená-los como artifacts permanentes do GitHub Actions.
