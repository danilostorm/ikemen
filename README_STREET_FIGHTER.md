# Ikemen GO – Street Fighter Alpha/Zero

Versão pronta para Windows baseada no Ikemen GO v1.0.0-rc.2.

## Conteúdo instalado

- 45 personagens do pacote Street Fighter Alpha/Zero
- 131 fases do pacote
- músicas das fases copiadas para `sound/`
- três personagens e oito fases de demonstração originais do Ikemen preservados
- seleção configurada em `data/select.def`

## Como iniciar

Execute `Ikemen_GO.exe`.
